# The Hub — Master Keyword Map

The permanent keyword inventory for gwhlds.com. This file is the **source**;
[`content-queue.md`](content-queue.md) is the **working set** of ~100 titles pulled from it.

- **Map** = every keyword we intend to own, forever. Thousands of rows.
- **Queue** = the next ~100 pages, ordered by strategy. Refilled from this map.
- **Ledger** (bottom of this file) = which batch of 100 is live, in flight, and next.

**Rule of the system:** when the queue drops below 20 unchecked items, pull the next
100 from this map into the queue, mark that batch in the ledger, and log it in the run report.

## Two kinds of keyword, and why we need both

| | **Head / "regular" keywords** | **Long-tail keywords** |
|---|---|---|
| Example | `day trading community` | `swing trading community with a day job` |
| Volume | High | Low, often <100/mo |
| Competition | Investopedia, Babypips, brokers | Almost none |
| Time to rank | 12–36 months | Weeks to months |
| Converts | Poorly | Well — the searcher is specific |
| AI citation odds | Low — crowded | **High** — few good answers exist |
| Our use | One **pillar** page each | One **spoke** page each |

The strategy is unchanged from the queue: **long-tail first, head terms earned later.**
A pillar page ranks because forty spokes link up to it, not because we wrote it first.
Head terms below are listed so we know what each cluster is aiming at — not so we chase them early.

**One keyword, one page. Always.** Before adding a row, search this file and the live slug
list. If the phrase is already targeted, link to that page instead of writing a competitor.

## The modifier library (this is what multiplies into thousands)

Every concept in the map crosses with these. `concept × modifier` is how a 500-row map
becomes a 5,000-page addressable surface. Only cross where a real person would search it.

**Question modifiers** — informational, best for AI citation
`what is` · `what does X mean` · `how to` · `how does X work` · `why does` · `when to`
`can you` · `should you` · `do you need` · `how long` · `how much` · `how many`
`is X worth it` · `is X safe` · `is X legit` · `what happens if` · `how to avoid`

**Comparison modifiers** — highest citation share of any format (~33%)
`X vs Y` · `difference between X and Y` · `X or Y` · `alternative to X` · `better than X`
`X compared to Y` · `which is best for X`

**Commercial modifiers** — the money queries, Phase 1 priority
`best` · `top` · `cheapest` · `free` · `paid` · `worth it` · `review` · `legit` · `scam`
`how much does X cost` · `X pricing` · `before you buy` · `red flags`

**Audience modifiers** — the cheapest ranking wins we have
`for beginners` · `for a small account` · `with a day job` · `part time` · `full time`
`with $500` · `with $1000` · `with $5000` · `under 25k` · `for students` · `after work`
`in the UK` · `in Canada` · `in Australia` · `outside the US`

**Market modifiers**
`forex` · `futures` · `stocks` · `indices` · `crypto` · `gold / XAUUSD` · `oil`
`ES` · `NQ` · `MES` · `MNQ` · `EURUSD` · `GBPUSD` · `USDJPY` · `SPY` · `QQQ`

**Platform / tool modifiers**
`TradingView` · `MT4` · `MT5` · `NinjaTrader` · `ThinkorSwim` · `Tradovate` · `cTrader`
`Discord` · `Telegram` · `Slack` · `mobile` · `on a phone` · `on one monitor`

**Timeframe / session modifiers**
`1 minute` · `5 minute` · `15 minute` · `1 hour` · `4 hour` · `daily` · `weekly`
`London open` · `New York open` · `Asian session` · `pre-market` · `power hour` · `overnight`

**Combinatorial yield (illustrative, not a licence to publish):**
30 chart concepts × 8 timeframes = 240 · 40 risk concepts × 6 audiences = 240 ·
25 setups × 12 markets = 300 · 20 platform tasks × 13 platforms = 260.
**Only publish a cross where the answer genuinely differs.** "RSI on the 5 minute" is a
real page; "RSI on the 7 minute" is not. That judgement is the whole job.

### How to pull the next batch (the "every 100, another 100" rule)

1. Trigger: `content-queue.md` has **fewer than 20** unchecked items.
2. Open the next batch row above. Take its clusters.
3. For every `MAP` spoke in those clusters, write the title as a **real page title**, not a keyword —
   the way a person would want it answered.
4. Kill any title that duplicates a live page's target phrase. Check the slug list first.
5. Append to the **end of the relevant phase** in `content-queue.md`. Never the top — order encodes strategy.
6. Flip the batch row to *In flight*, and mark the previous batch *Done*.
7. Say in the run report which batch was pulled and what was dropped for cannibalization.

### When the map itself runs low

Refill this file from, in order:
1. **Search Console** — queries where we rank 5–20. Fastest wins, beats inventing topics.
2. **Google PAA + autocomplete** on each head keyword above.
3. **Reddit** — r/Daytrading, r/Forex, r/FuturesTrading, r/Trading: questions asked weekly with no good answer ranking.
4. **Gaps** — any cluster with fewer than five live spokes, or any pillar not yet written.
5. **Modifier crosses** — only where the answer genuinely differs. That judgement is the job.

## Guardrails that apply to every row in this file

- **One keyword, one page.** Cannibalization splits ranking power and confuses AI retrieval.
- **A row is not a licence to publish.** Thin or near-duplicate pages get penalised as scaled
  content abuse and ignored by AI engines. If we cannot write something genuinely useful, we skip it.
- **Every page:** one verified outbound citation to a primary source and one specific sourced number.
- **Compliance is not optional:** no guaranteed returns, no invented statistics or testimonials,
  no "best/#1" self-superlatives, no personalised advice, footer disclaimer intact.
- Cluster 14 (taxes/business) and anything jurisdiction-specific always says rules vary and
  to consult a licensed professional.
